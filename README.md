# مِركاب | MIRKAB

منصة رقمية متخصصة لاكتشاف حلول وإكسسوارات السيارات العملية في المملكة العربية السعودية عبر التسويق بالعمولة (`Amazon.sa`)، بواجهة عرض ثلاثية الأبعاد ولوحة تحكم إدارية خاصة ومستقلة.

---

## التقنيات المستخدمة
- **HTML5** دلالي (دعم كامل للعربية `RTL` والإنجليزية `LTR`).
- **CSS3** خالص بدون أطر عمل خارجية (لوحة ألوان محددة: `#050505`، `#111214`، `#C5C7CA`، `#FFFFFF`، `#777777`).
- **Vanilla JavaScript (ES6+)** و**WebGL2** للمشهد ثلاثي الأبعاد.
- **التخزين المحلي**: `localStorage` لإعدادات الموقع وبيانات المنتجات، و**`IndexedDB`** لحفظ صور المنتجات المرفوعة من جهازك، دون أي قواعد بيانات خارجية أو خدمات مدفوعة.

## لوحة التحكم الإدارية (`/admin/`)
- منفصلة تماماً عن الموقع العام ولا يظهر لها أي رابط في القوائم أو التذييل.
- محمية بشاشة دخول محلية (عند أول استخدام يقوم المالك بإنشاء رمز دخوله محلياً دون تضمين أي كلمة مرور داخل الكود).
- تضم 8 أقسام تشغيلية كاملة:
  1. **الرئيسية**: ملخص الإحصاءات والوصول السريع.
  2. **المنتجات**: بحث، تصفية، ترتيب، إظهار/إخفاء (منشور/مسودة)، تعديل، وحذف بتأكيد.
  3. **إضافة منتج**: إضافة وتعديل كافة بيانات المنتج ورفع الصورة الرئيسية والصور الإضافية مع المعاينة.
  4. **الصور**: رفع ومعاينة وحذف وربط الصور مباشرة داخل `IndexedDB`.
  5. **روابط Amazon**: إدخال وتعديل ومسح واختبار روابط `Amazon.sa` والأسعار المؤكدة.
  6. **حسابات التواصل**: إدارة Instagram وTikTok وSnapchat وX وWhatsApp (تعديل/حذف/تفعيل/إخفاء).
  7. **إعدادات الموقع**: إدارة اسم العلامة التجارية والشعار وبيانات SEO وتغيير رمز الدخول المحلي.
  8. **النسخ الاحتياطي**: تصدير واستيراد نسخة احتياطية كاملة (`.json`) تشمل المنتجات والإعدادات والصور المرفوعة، مع خيار استعادة المنتجات الأساسية الـ 11 عند الحاجة.

> **تنبيه أمني صريح:** يعمل الموقع كموقع ثابت (Static Site) بدون خادم خلفي؛ لذا فإن المصادقة المحلية وحفظ البيانات في المتصفح مخصصان للتنظيم الشخصي على جهازك فقط، ولا يوفّران حماية أمنية خادمية ضد المتطفلين عند النشر العام.
