# مِركاب | MIRKAB

منصة رقمية متخصصة لاكتشاف حلول وإكسسوارات السيارات العملية في المملكة العربية السعودية عبر التسويق بالعمولة (`Amazon.sa`)، بواجهة عرض ثلاثية الأبعاد ولوحة تحكم إدارية خاصة ومستقلة مرتبطة بالكامل بـ **Supabase**.

---

## التقنيات المستخدمة
- **HTML5** دلالي (دعم كامل للعربية `RTL` والإنجليزية `LTR`).
- **CSS3** خالص بدون أطر عمل خارجية (لوحة ألوان محددة: `#050505`، `#111214`، `#C5C7CA`، `#FFFFFF`، `#777777`).
- **Vanilla JavaScript (ES6+)** و**WebGL2** للمشهد ثلاثي الأبعاد.
- **Supabase (`@supabase/supabase-js`)**:
  - جدول المنتجات: `public.products` (`id`, `category`, `status`, `sort_order`, `data`, `updated_at`)
  - جدول إعدادات الموقع وحسابات التواصل: `public.site_settings` (`id`, `data`, `updated_at`)
  - حاوية الصور السحابية: `product-images` (Supabase Storage)
  - المصادقة: **Supabase Auth** مقيّدة بحساب المالك فقط (`SUPABASE_OWNER_UID`) وسياسات **RLS** (بدون أي مفاتيح سرية في الواجهة الأمامية).

## لوحة التحكم الإدارية (`/admin/`)
- منفصلة تماماً عن الموقع العام ولا يظهر لها أي رابط في القوائم أو التذييل.
- محمية بتسجيل الدخول عبر **Supabase Auth** (بريد المالك وكلمة المرور فقط، دون إمكانية إنشاء حسابات جديدة، ومع التحقق الصارم من `SUPABASE_OWNER_UID`).
- متوافقة مع الاستضافة تحت المسار الفرعي لـ GitHub Pages (`/mirkab-website/`).
- تضم 8 أقسام تشغيلية متصلة بـ Supabase:
  1. **الرئيسية**: ملخص الإحصاءات وحالة الربط مع Supabase والوصول السريع.
  2. **المنتجات**: بحث، تصفية، ترتيب، إظهار/إخفاء (`published`/`draft`)، تعديل، وحذف مع تنظيف الصور المرتبطة.
  3. **إضافة منتج**: إضافة وتعديل كافة بيانات المنتج ورفع الصورة الرئيسية والصور الإضافية إلى `product-images`.
  4. **الصور**: رفع ومعاينة وحذف وربط الصور مباشرة داخل **Supabase Storage (`product-images`)**.
  5. **روابط Amazon**: إدخال وتعديل ومسح واختبار روابط `Amazon.sa` والأسعار المؤكدة.
  6. **حسابات التواصل**: إدارة Instagram وTikTok وSnapchat وX وWhatsApp (تظهر الأيقونات الخمس دائماً في التذييل وتُفعّل الروابط عند إضافتها وتفعيلها).
  7. **إعدادات الموقع**: إدارة اسم العلامة التجارية والشعار وبيانات SEO وتغيير كلمة مرور المالك عبر Supabase Auth.
  8. **النسخ الاحتياطي والمزامنة**: تصدير واستيراد نسخة احتياطية كاملة (`.json`) ومزامنة/تهيئة المنتجات الـ 11 والصور إلى Supabase دون تكرار.
